# NIVARA Mobile App Frontend

NIVARA is an accessible, AI-powered assistant for individuals with neurodivergent needs, autism, and sensory sensitivity, as well as their caregivers.

## Features
- 🗣️ **AAC & Expressive Communication**: Visual grid boards, text-to-speech, emotion logging, quick needs.
- 📅 **Routine & Interactive Learning**: Step-by-step visual schedules, interactive learning cards, AI tutor.
- 🧘 **Sensory Monitoring & Regulation**: Real-time noise meter, brightness tracking, crowd level indicators, and soothing response suggestions.
- 🆘 **Safety & Smart GPS Tracking**: One-tap SOS, safe zone geofences, live map view, connected wearable band status.
- 👩‍👧 **Caregiver Monitoring Dashboard**: Real-time child safety status, location tracking, routine adherence, and battery/connection telemetry.
- 🤝 **Community & Peer Support**: Peer chat groups, caregiver community posts, resource sharing, and direct messaging.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Expo development server:
   ```bash
   npm run start
   ```
